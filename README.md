# DEV TV Theme Switcher

This example demonstrates how to dynamically switch between different color themes (Graphite, Walnut, Cream) for a web page using plain HTML, CSS, and JavaScript. It simulates the user experience enhancement by allowing users to select their preferred visual style.

## Language

`html`

## How to Run

Open the `index.html` file in your web browser. Click the theme buttons to switch the page's appearance.
